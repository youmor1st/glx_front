# Настройка системы авторизации

## Описание

Реализована система авторизации для Telegram Mini App с возможностью:
- Входа по логину и паролю
- Привязки Telegram ID к аккаунту
- Автоматического входа через Telegram после первой привязки

## Структура файлов

### API сервис (`src/services/api.ts`)
- Интеграция с бэкенд API
- Типы данных для всех эндпоинтов
- Axios interceptors для автоматического добавления токенов

### Store авторизации (`src/store/authStore.ts`)
- Zustand store для управления состоянием авторизации
- Персистентное хранение данных пользователя
- Методы для входа через логин/пароль и Telegram

### Компоненты
- `LoginPage` - страница входа с полями username/password
- `StudentDashboard` - главная страница для студентов
- `App` - главный компонент с роутингом

## Настройка

### 1. Переменные окружения
Создайте файл `.env.local` в корне проекта:
```env
VITE_API_URL=http://localhost:3000
```

### 2. Запуск приложения
```bash
npm install
npm run dev
```

### 3. Настройка бэкенда
Убедитесь, что бэкенд API доступен по адресу, указанному в `VITE_API_URL`.

## Логика работы

### Первый вход
1. Пользователь вводит логин и пароль
2. Система авторизует пользователя через `/auth/login`
3. Получает токен доступа и данные пользователя
4. Telegram ID автоматически привязывается к аккаунту

### Последующие входы
1. При открытии приложения проверяется наличие токена
2. Если токен валидный - пользователь автоматически входит
3. Если токен недействителен - показывается форма входа

### Telegram интеграция
- При первом входе через Telegram данные пользователя сохраняются
- В дальнейшем можно использовать кнопку "Войти через Telegram"
- Telegram ID привязывается к аккаунту для автоматического входа

## API эндпоинты

### Авторизация
- `POST /auth/login` - вход по логину/паролю
- `POST /auth/telegram-login` - вход через Telegram
- `GET /auth/me` - получение данных текущего пользователя

### Студенты
- `GET /students/profile/{id}` - профиль студента (публичный)
- `GET /students/me` - мой профиль (авторизованный)
- `GET /students/me/history` - история баллов
- `GET /students/leaderboard` - рейтинг
